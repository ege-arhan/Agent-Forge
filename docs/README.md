## Results

OFFLINE (scripted) and REAL (model provider) results are kept apart and never
combined or compared.

| What | Where |
|---|---|
| Dogfooding program: agents, suites, how results are produced | [dogfood/README.md](../dogfood/README.md) |
| REAL: the limited real-model validation and its caveats | [REAL_MODEL_BENCHMARK.md](REAL_MODEL_BENCHMARK.md), `dogfood/results/real/` |
| OFFLINE: scripted reference results (pipeline validation only) | `dogfood/results/offline/` |
